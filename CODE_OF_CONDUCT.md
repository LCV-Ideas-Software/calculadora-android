# Code of Conduct

This repository adopts the **Contributor Covenant 3.0** as its community
standard. The full canonical text is available at:

- https://www.contributor-covenant.org/version/3/0/code_of_conduct/
- https://www.contributor-covenant.org/version/3/0/code_of_conduct/code_of_conduct.md

By participating in this project, you agree to follow the Contributor
Covenant 3.0 standard linked above.

## Scope

This code applies to issues, pull requests, discussions, review comments,
documentation changes, maintainer interactions, and any channel where
participants represent this repository or LCV Ideas & Software.

## Reporting

Report conduct concerns privately to LCV Ideas & Software at `conductcode@lcv.dev`.
Do not open a public Issue for private conduct, security, legal, fiscal, or
personal matters.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block accounts,
or take other proportionate action guided by the Contributor Covenant 3.0
enforcement model.
